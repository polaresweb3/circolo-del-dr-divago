# Requisiti di sicurezza

Richiedere sempre la conferma esplicita dell’utente immediatamente prima di:
- unire una pull request o un branch in main o eseguire gh pr merge;
- pubblicare in produzione, incluso attivare o aggiornare GitHub Pages;
- pubblicare immagini Docker/OCI;
- creare o inviare release o tag Git;
- creare, modificare, ruotare o eliminare segreti o infrastruttura di produzione.

Indicare l’azione e la destinazione esatte. La conferma deve essere specifica e comparire nella risposta immediatamente precedente dell’utente.
Non includere nel repository audio, video scaricati, trascrizioni integrali, credenziali o l’archivio privato.
