# Autorizzazioni per il Circolo del Dr Divago

Queste istruzioni specifiche prevalgono sui requisiti globali di conferma per il repository `polaresweb3/circolo-del-dr-divago`.

## Git e pubblicazione del sito

- Per `polaresweb3/circolo-del-dr-divago`, le richieste dell'utente di modifica al sito autorizzano anche commit, push su `main` e aggiornamento di GitHub Pages, senza ulteriori conferme.
- Una richiesta esplicita dell'utente di fare push, unire le modifiche, pubblicare o aggiornare il sito autorizza l'azione richiesta, anche su `main`, e l'aggiornamento di GitHub Pages che ne consegue.
- Non chiedere una seconda conferma, una formula particolare o una conferma nella risposta immediatamente precedente. Usa la destinazione già identificata nella conversazione.
- Per questo flusso, la richiesta esplicita sostituisce i precedenti obblighi di conferma separata per merge in `main`, `gh pr merge` e pubblicazione in produzione del sito.
- Esegui prima le verifiche appropriate e includi soltanto le modifiche pertinenti alla richiesta. Conserva il lavoro locale non pertinente.
- Una richiesta di sola revisione o anteprima, senza modifiche richieste al sito, non autorizza da sola la pubblicazione. Rispettare sempre un'eventuale richiesta esplicita di non pubblicare.

## Altre operazioni

Restano validi gli obblighi globali di conferma specifica per immagini Docker/OCI, release e tag Git, segreti e infrastruttura di produzione e deploy estranei a questo sito.
